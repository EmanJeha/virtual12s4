## Set up (once)
1. Create a **public** repository named `virtual12s4`.
2. Upload `index.html`, `board.html`, `lab.html` and this README.
3. Settings → Pages → Source: **Deploy from a branch** → `main` / root → Save.
4. After about a minute the links above work. The lesson page already points to them.

## In class
- Open the game screen in the lesson page, then click **Open live leaderboard** and share that tab.
- Paste the game link in the chat (or show the QR). Students type their first name and play.
- **New round** on the leaderboard clears the scores for a second class on the same day.
- Scores travel through the free ntfy.sh relay on a topic for today’s date only. Only first names and scores are sent.
- The lab runs real Python in the browser (Pyodide). An endless loop is stopped after 4 seconds.
